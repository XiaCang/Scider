# 知识图谱场景问答功能

## 功能描述

在知识图谱界面，用户输入自然语言问题，后端基于当前图谱可见的论文子集（四要素）调用 LLM 返回答案。

---

## 改动文件

### 1. `app/core/prompts.py`

新增两个导出项：

- **`GRAPH_QA_SYSTEM_PROMPT`**：系统提示词，限定 LLM 仅基于提供的论文集合作答，引用格式为「《论文标题》」。

- **`build_graph_qa_user_prompt(papers, question, max_chars_per_paper=300, max_total_chars=8000) -> str`**：将论文列表压缩为结构化文本后拼入 Prompt。每篇论文展示标题、作者、年份及四要素，单篇截断上限 300 字，全部论文总字数超 8000 时自动截断并标注。

### 2. `app/api/routes/graph.py`

新增端点：

```
POST /api/graph/ask
```

**请求体（JSON）**

| 字段 | 类型 | 说明 |
|------|------|------|
| `question` | `string` (1–500字) | 用户自然语言问题 |
| `paper_ids` | `string[]` (≥1) | 图谱当前可见的论文 ID 列表，由前端传入 |

**响应（成功）**

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "answer": "...",
    "paper_count": 5
  }
}
```

**处理流程**

1. JWT 鉴权（与其他图谱接口一致）
2. 按 `paper_ids` + `user_id` 查询 `Paper LEFT JOIN KeyPoints`，防止越权
3. 构造压缩摘要（`build_graph_qa_user_prompt`）
4. 通过 `run_in_executor` 在线程池中调用同步的 `chat_completion`，不阻塞 FastAPI 事件循环
5. 返回答案和实际命中论文数

## 后端整体架构（简要）

```
src/backend/
├── app/
│   ├── main.py                      # FastAPI 入口，挂载路由、启动迁移
│   ├── core/
│   │   ├── config.py                # 环境变量配置（LLM/Embedding/DB）
│   │   ├── llm_client.py            # OpenAI 兼容 LLM 调用（DeepSeek / Qwen）
│   │   ├── embedding_client.py      # Embedding API
│   │   ├── prompts.py               # 所有 Prompt 模板 ← 本次修改
│   │   ├── graph_similarity.py      # 余弦相似度计算
│   │   └── graph_llm_clustering.py  # LLM 主题聚类
│   ├── api/routes/
│   │   ├── papers.py                # 论文 CRUD、单篇 AI 问答
│   │   ├── graph.py                 # 知识图谱接口 ← 本次修改
│   │   ├── graph_edit.py            # 自定义节点/边
│   │   └── chat_ws.py               # WebSocket 多轮对话
│   └── tasks/                       # Celery 异步任务（PDF解析、LLM提取、向量化）
├── db/
│   ├── models.py                    # SQLAlchemy ORM
│   ├── session.py                   # 异步数据库会话
│   └── crud_*.py                    # 各实体 CRUD 操作
└── middleware/
    └── jwt_middleware.py            # JWT 认证
```

### 关键数据库表

| 表 | 核心字段 |
|----|---------|
| `paper` | id, title, authors, year, abstract, full_text, status, user_id, folder_id |
| `key_points` | paper_id, background, methodology, innovation, conclusion, is_confirmed |
| `paper_embedding` | paper_id, embedding (JSON), model_name |
| `graph_node` | id, user_id, paper_id, name, node_type, category, properties |
| `graph_edge` | id, user_id, source_id, target_id, relation_type, label |
| `graph_llm_cache` | user_id, folder_id, papers_hash, clusters, nodes, edges |

### 知识图谱问答数据流

```
前端图谱界面
  │  paper_ids（当前可见节点）+ question
  ▼
POST /api/graph/ask
  │  查询 Paper + KeyPoints（user_id 隔离）
  │  build_graph_qa_user_prompt()  ← 压缩为 ≤8000 字摘要
  │  run_in_executor → chat_completion()
  ▼
LLM（DeepSeek / Qwen）
  ▼
{ answer, paper_count }
```
